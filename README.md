# Noor Alshater - Cybersecurity Portfolio

Single-page portfolio in plain HTML, CSS and JavaScript (no build step).

## Files
- `index.html` - page structure
- `style.css` - themes, layout, project gallery
- `script.js` - theme, language (EN/AR), navigation, project gallery + details, certificate viewer, contact form
- `assets/` - photo, CV, certificate, reports; `assets/projects/` holds the project preview images

## Edit projects
All project text (problem, goal, approach, result, links) lives in the `PROJECTS` array in `script.js`, in English and Arabic.

## Run
Open `index.html` in a browser. Keep the `assets` folder beside it.
